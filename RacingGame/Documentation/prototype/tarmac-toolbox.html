About Racing Game's Tarmac Toolbox

    
Version 

    
A free, in-browser track editor for Racing Game, the desktop racing game. Design a closed-loop circuit, let the checks catch problems, and export a .Track file the game can load. It does not work with other games.

    
How it works

    
    
      
  1. Design a track: add blocks, drag the road, shape the terrain, or trace an outline.
    2. 
      
  2. Fill in your name as Author and press Export track.
    3. 
      
  3. Save the downloaded .Track file in the game's Tracks folder (the export window shows the path for your system).
    4. 
      
  4. Start Racing Game, choose Play, then the Custom button on the track selection screen.
    5. 
    

    
Your work and your tracks

    
Everything stays in your browser. The editor keeps your current track in this browser's local storage so a reload does not lose it, and nothing is uploaded. Your name is written into the track file as its Author. Use the name you want credited.
