## Description: paste this HTML

**CHECK** that itch's description box accepts HTML (it has an HTML or source view). If it only takes rich text, paste the preview of this block instead. Only basic tags are used, so it should survive either way.

```html
<h2>Your network. Your track. Zero servers.</h2>
<p><strong>Racing Game: LAN Edition</strong> is a fast 3D arcade racer for up to four players on the same Wi-Fi or LAN, with a track editor that runs in your browser, so you can build the circuit before you race it.</p>

<h2>Why LAN?</h2>
<ul>
  <li>No sign-up</li>
  <li>No servers to go offline</li>
  <li>No data harvested</li>
  <li>Same room, same snacks</li>
</ul>

<h2>How a race goes</h2>
<ol>
  <li>Pick <strong>Play</strong>, then <strong>Multi Player</strong> on LAN.</li>
  <li>One player hosts, the others join from the lobby.</li>
  <li>Choose your cars and the number of laps (1 to 5).</li>
  <li>Ready up and race.</li>
</ol>
<p>Prefer to race alone? Single player has three tracks (Beginner, Advanced and Expert), best times and a ghost car to beat.</p>

<h2>Build your own tracks</h2>
<p><strong>Racing Game's Tarmac Toolbox</strong> is a free track editor that runs right here in your browser. Draw a closed-loop circuit, drag the road, sculpt the hills, add tunnels and palms, and let the built-in checks catch problems. Press Export, drop the <code>.Track</code> file into the game's Tracks folder, then pick <strong>Custom</strong> on the track selection screen.</p>
<p>Every track records its author, so credit travels with it. Post your <code>.Track</code> files in the comments to share them.</p>

<h2>What you need</h2>
<ul>
  <li>A Windows, macOS or Linux computer</li>
  <li>Two or more players on the same network (or just you, for single player)</li>
  <li>A keyboard, mouse or gamepad</li>
</ul>

<h2>Open source, built with MonoGame</h2>
<p>The code for the game and the editor is available on request: just ask in the comments. #BuiltWithMonoGame</p>
<p>Based on the Racing Game Starter Kit; MonoGame port by Infinite Space Studios. Racing Game: LAN Edition by Dominique Louis (CartBlanche).</p>
```

**CHECK** the credit line against the original starter kit licence before publishing.
