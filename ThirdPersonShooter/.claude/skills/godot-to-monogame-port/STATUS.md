## 2026-11-17 lighting pass 2 (verified by image stats + eyeball)
- Verified: level frame vs Godot start frame: luma 0.219 vs 0.207, saturation 0.536 vs 0.587, hue 32 vs 33; contrast (luma std) 0.113 vs 0.153 is still ~26% low. Method: Tools/ImageStats/imagestats.py (stdlib PNG decoder) gives a numeric gap so tuning can stop on a stall rule instead of endless eyeballing.
