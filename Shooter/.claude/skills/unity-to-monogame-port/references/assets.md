# Assets (textures, audio, fonts)

Everything under `Textures/ Audio/ Fonts/ Models/` plus the `.mgcb` and `AssetMap.json` is generated by a ContentGen script from the extractor's `asset-manifest.json` and the Unity `.meta` files. Do not edit `.mgcb` by hand.

`AssetMap.json`: `assets[<Unity asset path>] -> { name, type, ...metadata }` plus `guidIndex[guid] -> path`. `name` is the `ContentManager.Load<T>` name. Types: Texture2D, Sprite (loads as Texture2D), SoundEffect, Song, SpriteFont, Model.

## Textures
- Copy from the Unity folders. Flatten `.psd`, `.tga`, 16-bit PNG, and files whose extension lies (a JPEG inside `.png`) to 8-bit PNG with ImageMagick; record `convertedFrom`.
- Processor: `TextureProcessor`, `TextureFormat=Color`, **`ColorKeyEnabled=False`** (default True punches out magenta), **`PremultiplyAlpha=False`** (Unity blends straight alpha; metallic-smooth alpha is smoothness; use `BlendState.NonPremultiplied` for sprites), no power-of-two, no square. `GenerateMipmaps` = Unity's `enableMipMap` (3D/VFX yes, UI and skybox no).
- **Size:** like Unity's player build, downscale non-UI textures to the `DefaultTexturePlatform maxTextureSize` (512 there). UI sprites and skybox keep full size. Provide `--full-res`.
- **`alphaUsage: 2` (Alpha Source: From Gray Scale):** white-on-black particle textures get their alpha from brightness. The generator must convert (alpha = Rec709 luma, before the size cap) or particles render as opaque squares with black around them. Record `alphaFromGrayScale`.
- **Skybox:** equirectangular 4096x2048 fits HiDef's 4096 limit. Skybox/Panoramic output = `tex.rgb * Tint.rgb * unity_ColorSpaceDouble (~4.59 linear) * Exposure`. Lookup with `d` the view direction in UNITY space: `lat = acos(d.y)`, `lon = atan2(d.z, d.x)`, `u = 0.5 - lon/(2pi)`, `v' = lat/pi`.
- Sampler state from AssetMap: wrap repeat/clamp, filter point/bilinear/trilinear. `alphaIsTransparency` (colour dilation) not reproduced.
- Emission map quirk: the Blaster emission map must be sampled **without** the sRGB decode to match Unity; other emission maps untested.

## Audio
- Long loops (music/ambience) -> `Song` (`MediaPlayer.IsRepeating = true`); everything else -> `SoundEffect` (Quality=Best). MP3 SFX go through the bundled FFmpeg, no manual conversion. Spaces become `_` in content names.
- Keep `playback` metadata: `loop`, `spatialBlend` (0 = 2D, 1 = 3D), `minDistance`/`maxDistance`, `volume`. These come from AudioSource components on prefabs (not baked automatically; bake what you need).
- 3D: Unity logarithmic rolloff `min / distance` (full volume inside min, flat beyond max), volume blended 1 -> gain by spatial blend, pan = blend x side of camera. Remember the Z flip for emitter positions. OpenAL only approximates Unity's mixer.
- Mixer groups: read `MainAudioMixer` snapshot values (dB). A gain above 1 cannot be played; cap at 1 (Unity would clip).
- Master volume = `SoundEffect.MasterVolume`.

## Fonts (TextMeshPro)
- TMP SDF assets are atlases, not TTFs. Find the TTF (project fonts, or the identical family in `Library/PackageCache/...`) and check its licence; copy the licence text.
- Generate spritefonts for each size found in TMP `m_fontSize` / auto-size maximums in scenes + prefabs. MonoGame `Size` is points, so draw at `0.75 x (Unity size / nominal size)` to match TMP pixel sizes.
- Not reproduced: bold/italic (apply `ToUpperInvariant()` for UpperCase transform), SDF outlines/shadows, rich text.
- Read each canvas's CanvasScaler reference resolution from the extractor JSON before laying out text.

## Unresolved GUIDs
The manifest lists GUIDs with no asset in the project. Usually harmless: built-in cubemap slot, editor-only preview textures, generated LightingSettings, mixer exposed-parameter ids, missing OBJ material remaps. Check each once, note it, move on.

## Not imported
Import only what the scenes reference. To add something else (an unused model, a prefab outside the scenes) use the extractor's `--extra <asset path>` and rerun ContentGen.
